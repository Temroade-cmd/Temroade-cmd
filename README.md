### `01` &nbsp; Heart Alert, aide à la décision clinique

> Projet d'équipe, mémoire de M2 noté 19,5/20, initiative Startup 1275.

```
  patient ──▶  FastAPI  ──▶  XGBoost  ──▶  risque %  ──▶  HeartBot
    │          JWT · SQL     93,7 %        AUC 97,2 %     Gemini 2.0
    └──────────────  application Flutter (MVVM)  ◀──────────────┘
```

| Brique | Détail |
|---|---|
| **Modèle** | XGBoost entraîné sur 1190 patients (UCI), comparé à 5 autres algorithmes |
| **Backend** | FastAPI, PostgreSQL, authentification JWT, export PDF |
| **Mobile** | Flutter en architecture MVVM, gestion des patients et historique |
| **Assistant** | HeartBot, chatbot médical nourri par la prédiction et le dossier du patient |

**Code** &nbsp; [`heart-alert-backend`](https://github.com/Temroade-cmd/heart-alert-backend) &nbsp;·&nbsp; [`heart-alert-frontend`](https://github.com/Temroade-cmd/heart-alert-frontend)
